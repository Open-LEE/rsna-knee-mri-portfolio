# 实验记录摘要

本文件按实际工作顺序整理，非逐日流水账。公开榜成绩和最终排名由参赛者反馈；本地聚合指标从收到的结果包核查。参赛者补充的最终私榜 AUC 为 **0.942**，队伍 **Open_LM**；未独立联网核验。

| 阶段 | 要解决的问题 | 工作与结果 |
|---|---|---|
| 数据工程 | 原始 DICOM 体积大，重复处理慢 | 先 10 例烟雾测试，后全量 4,407 例；保存约 4.94 GiB 缓存 |
| 监督信号 | 仅 58 例完整官方标签 | 尝试多语言报告提取与证据检查；最后接入公开报告弱标签，未知保留为缺失 |
| 初期训练 | 验证训练到提交流程 | ResNet18 弱监督 5 轮，58 例参考 AUC 约 0.7954；不能作为独立泛化结果 |
| 公开方案复现 | 建立强图像基线 | 复现 CoAtNet 与 R6/R7，公开榜逐步到 0.956、0.958 |
| 推理工程 | 多模型 DICOM 重复解码与超时 | 实现输入指纹缓存、镜像预测对照、时间预算、结果对齐与回退 |
| DINO 特征 | 测试新的图像分支 | 冻结特征头开发集 0.7806，保留集 0.8047 |
| 两层/四层对照 | 适应 MRI 图像分布 | 保留集分别 0.8092 / 0.8151；选择轮次依据开发集，保留集已查看，不能继续视为盲测 |
| 单模型融合 | 能否补充强基线 | 5% DINO 公开榜 0.955，拒绝作为最终改进 |
| 版本诊断 | 掉分是否来自 timm 差异 | 15 例中 1.0.25 与 1.0.29 特征及概率相同，不支持此解释 |
| OOF 资料检查 | 能否可靠优化 R6/R7 融合 | 挂载公开包无可用的完整折外预测组合，不能拿不明确的样本当独立验证 |
| 自己的三折 | 比较冻结与微调 | 4,292 例，微调每折均提升；平均 0.7913→0.8111，约 54 分钟 |
| 三折融合 | 最后一次有限探索 | 三折 DINO 固定 2%，公开榜 0.957；仍低于原 0.958 |
| 收尾 | 避免继续无依据扫参数 | 推荐保留原始 robust v2 与镜像 v4 两个成功方案；参赛者反馈最终私榜 0.942，排名 1634/6425 |

## 如何读结果

- “更好弱标签 AUC”仅表示更符合报告标签，不证明更符合隐藏评测真值。
- 新模型单独更好不代表加入现有集成后更好；误差相关性及校准都可能影响融合。本项目没有足够证据定位唯一原因。
- 公开榜仅使用部分测试数据；最终排名不能由公开榜 0.958 推算。
- 可见测试仅 3 例，能验证程序输出，不足以证明隐藏测试完整覆盖或运行时长。
- 记录最终选择是推荐，未保存确认两个勾选已落盘的证据，因此不把它写成已核实事实。

`results/` 保留开发/保留集对照和三折聚合核查 JSON，不发布病例级标签、报告或预测。
