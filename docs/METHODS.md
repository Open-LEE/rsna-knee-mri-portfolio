# 方法与实现边界

## 1. 数据与标签

训练集共 4,407 例，仅 58 例有完整官方标签，其余 4,349 例官方 12 类标签缺失。使用公开 `pilkwang/rsna-knee-llm-labels` 报告标签作为弱监督，YES→1、NO→0、UNK→缺失。初期也开展了多语言报告的证据定位和 ACL 标签提取试验；未声称自行生成最终全部弱标签。

损失只对已知标签计算 BCE，各可用类别归一化后平均。未知标签不会以负样本形式参与梯度计算。分类头测试覆盖未知标签的梯度屏蔽。

## 2. 自有训练分支的图像输入

`src/knee/preprocess.py`：从候选序列选择三个方向，排序 DICOM 切片，选取 12 张切片；处理像素缩放和 MONOCHROME1，缩放至 224×224，并按分位数归一化为 uint8。输出每例 `x[3,12,224,224]` 和方向有效性掩码。每例均匀抽片可能遗漏小病灶，是当前方法局限。

`src/dino_branch_train.py` 使用灰度复制三通道、ImageNet 均值方差，DINOv2 ViT-S/14 输出 384 维特征。聚合头以 LayerNorm、128 维投影和位置参数表示方向与切片，通过每类别独立的注意力与 value 分支汇总 36 张图像，输出 12 个 logits；缺失方向被注意力掩码排除。

## 3. 微调和分组验证

冻结实验训练头 20 轮。后续对照分别解冻最后 2 / 4 个 Transformer block 及最终 norm。编码器学习率 1e-5，分类头 1e-4，AdamW、余弦调度、FP16、batch=2、梯度累积=4。训练路径支持双 GPU DataParallel，不声称进行了分布式训练框架优化。

原固定划分按归一化报告哈希、相同影像张量哈希建立连通组；与官方参考病例连通的弱标签病例被排除。哈希分组只能排除所捕获的重复，不能证明没有患者层面或近重复泄漏。

三折实验合并旧 train/dev/holdout 的 4,292 例，固定随机种子 20261022，按组大小平衡，折大小 1431/1431/1430。每折重新初始化分类头、从通用预训练编码器开始。固定 20 轮头训练与 6 轮四层微调，不用外层验证挑轮次。记录每折训练/验证 ID 与 OOF。

架构此前已在这批数据上开发过，因此三折对照不是全新的独立最终测试。58 例官方参考样本少且多次查看；不据此优化公开集成的权重。

## 4. 最终集成的完整分支融合公式

设 `rank` 为同一测试集合内按类别的百分位排名：

```text
coat = 0.65 * rank(CoAtNet384) + 0.35 * rank(CoAtNet224)
conv = 0.80 * rank(R6) + 0.20 * rank(R7)
score[c] = w[c] * coat[c] + (1 - w[c]) * conv[c]
```

`w` 默认 0.5，Lateral OA=0.2、PF OA=0.6、Synovitis=0.8、Baker's=0.35。上述比例继承公开方案及对应实验实现，未宣称用独立验证求得最优值。R6/R7 各为四折 ConvNeXt 分支，公开包另有辅助预测/stacker，保留其原始实现。镜像 v4 对 R7 增加镜像预测，原始 robust v2 不增加此项。

`src/ensemble_reference.py` 仅实现所有分支完整成功时的融合公式。原比赛推理还包括独立预处理、缺失分支回退、权重加载、预算及输出对齐；不要把此参考函数当成完整参赛推理。

排名融合输出是排序分数，不代表已校准的临床概率。

## 5. 工程实现与负结果

- 缓存复用受输入指纹约束，不能混用不同分辨率或取片逻辑。
- 对指定权重使用 SHA256 核对版本；输出 ID、列顺序及数值范围检查。
- DINO 最后实验三折概率平均后占排名融合的 2%；全量覆盖不足时整份回退基线。
- 该三折候选公开榜 0.957，低于基线 0.958；先前单模型 5% 为 0.955。
- timm 1.0.25 / 1.0.29 对 15 个检查样本的特征和概率相同，仅支持样本范围内的一致，不证明全部输入等价。

没有可用的 R6/R7 同病例折外预测，故无法可靠估计其与 DINO 的验证互补性。最终不采用负收益融合，是实验结果驱动的取舍。
