# 简历与面试说明

## 简历短版

**膝关节 MRI 多标签异常检测｜Kaggle RSNA｜1634/6425（前 25.4%）**

- 构建覆盖 4,407 例 MRI 的 DICOM 预处理、缓存与弱监督训练流程，实现 12 类异常检测。
- 复现公开 R6/R7/CoAtNet 集成，开展 DINOv2 部分微调、三折分组交叉验证及融合对照实验，最终私榜 AUC **0.942**，公开榜最佳 AUC 0.958。

## 一分钟介绍

这个项目是用膝关节 MRI 识别 12 类异常。主要困难是四千多例训练检查中只有 58 例有完整官方标签，以及 MRI 序列多、解码和推理成本高。我完成了三方向切片缓存、公开报告弱标签接入、未知标签掩码训练，以及按相同报告和影像分组的验证流程。在模型方面，我复现公开强集成，同时训练 DINOv2 分支比较冻结和部分微调。微调提升了弱标签验证结果，但加入强集成后公开榜下降，因此最终没有采用这个分支。项目最高公开榜 AUC 是 0.958，最终私榜 AUC 0.942，排名 1634/6425。

## 面试可以讲清楚的三个取舍

1. **为什么不把缺失标签当 0？** 未知不等于阴性；大量错误负样本会污染训练，因此损失只覆盖已知标签。
2. **为什么验证集改善，融合却掉分？** 弱标签目标与真实评测存在偏差，而且单模型改善不意味着与基线互补；本项目也缺少强基线同病例 OOF，不能证明具体原因。
3. **怎么降低验证泄漏？** 归一化报告与影像哈希连通组不跨折；这是针对精确重复的措施，不能夸大为患者层面完全无泄漏。
